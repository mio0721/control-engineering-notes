# 第 14 课复习：增益裕度与相位裕度

## 一句话

PM 看增益交越（0 dB）处离 $-180^\circ$ 还差多少；GM 看相位交越（$-180^\circ$）处离 0 dB 还差多少。

## 读图步骤

1. 确认曲线是开环环路 $L(s)=C(s)P(s)$。
2. 找幅频图 0 dB 点 $\omega_{gc}$，读同频率相位。
3. $\mathrm{PM}=180^\circ+\arg L(j\omega_{gc})$。
4. 找相频图 $-180^\circ$ 点 $\omega_{pc}$，读同频率幅值。
5. $\mathrm{GM}_{dB}=-|L(j\omega_{pc})|_{dB}$；线性 $\mathrm{GM}=10^{\mathrm{GM}_{dB}/20}$。
6. 检查多个交越点、开环稳定性与反馈结构。

## 易错点

- 不要把 PM、GM 的读取频率交换。
- -10 dB 对应 GM=+10 dB，约 3.16 倍。
- GM 是倍数；PM 是角度。
- 延迟和滤波会增加相位滞后，可能减少 PM。
- 裕度是模型相关的余量指标，不等于非线性真实设备的安全保证。

## 本模型校验

$L(s)=K/(s+1)^3$：

$$
\omega_{pc}=\sqrt3,\qquad \mathrm{GM}=8/K
$$

$K=4$ 时 GM=2（6.02 dB）；$K=8$ 时 GM=1（0 dB），闭环到达临界边界。

3. 提高控制增益为何可能让系统响应变快但更易振荡？
