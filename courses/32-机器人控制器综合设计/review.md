# 第 32 课复习：机器人控制器综合设计

## 控制结构

目标轨迹 → 误差 → PID → 力矩限幅 → 电机与关节 → 测量与滤波 → 反馈。

$$
e=q_d-q,\qquad \tau_{raw}=K_pe+K_i z-K_d\dot q_f
$$

## 各部分职责

- P：根据当前误差纠正。
- I：消除持续偏差，需 Anti-Windup。
- D：从速度提供阻尼，需注意噪声。
- 滤波：降噪但增加滞后。
- 限幅：遵守执行器能力。

## 简化设计顺序

定义指标与硬限制 → 建立对象模型 → 调 P/D → 检查闭环响应和开环裕度 → 加滤波与适量 I → 验证饱和、负载、延迟和异常输入。

## 易错点

- 单位不一致会让增益失去意义。
- 限幅后积分仍累积会产生 windup。
- 只看阶跃曲线不能证明鲁棒。
- 仿真通过不代表通信、采样和执行器都安全。

## 自测

1. 为什么先调 P/D，再加积分通常更容易定位问题？
2. 速度滤波为什么会影响相位裕度？
3. 设计验证至少记录哪些对象、参数、轨迹与输出指标？
