# 文件夹索引

| 目的 | 位置 | 说明 |
| --- | --- | --- |
| 阅读网站 | [首页](../index.html) | 双击可离线阅读 |
| 修改课程内容 | `courses/stage-0/`～`courses/stage-4/` | 按阶段、课号查找 |
| 查看课程讲解 | `lessons/` | 自动生成，勿直接编辑 |
| 查看复习笔记 | `reviews/` | 自动生成，勿直接编辑 |
| 查看公式手册 | `formulas/` | 自动生成，勿直接编辑 |
| 修改公共样式与交互 | `assets/` | 包含公式库、主题和共享演示 |
| 查阅旧版材料 | `archive/courses/` | 保留原内容，不参与构建 |
| 查看维护说明 | `docs/` | 路线、发布方法与移动清单 |
| 构建网页 | `tools/build.py` / `tools/更新网站.bat` / `tools/更新网站.sh` | 集中保存在 tools/ |
| 构建回归检查 | `tests/` | 在临时目录验证，不改正式课程 |

## 单课目录

```text
courses/stage-N/课号-课程名/
├── course.json       阶段标记
├── lesson.md         完整讲解
├── review.md         复习笔记
├── formulas.md       公式手册
├── media/            本课图片与附件（按需）
├── demos/            本课独立交互演示（按需）
└── simulation.py     本课仿真代码（按需）
```

图片、演示和仿真留在所属课程旁边，避免统一搬走后难以判断归属。`.git/` 是版本记录；`__pycache__/` 是运行时缓存，已由 Git 忽略。

## 同级参考资料

网站仓库外的 `Control/DR_CAN/` 按课程名称保存 PDF、Simulink 模型和相图工具压缩包；`Control/MatLab/Lesson/` 保存 MATLAB 练习。它们不是网页生成源文件，不随网站构建移动。
